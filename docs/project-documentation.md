# Library Management System – Project Documentation

## Project Overview

The Library Management System is a DBMS project designed to manage books, authors, publishers, members, loans, and fines.

## Database Components

- Publisher
- Author
- Book
- Book_Author
- Member
- Loan
- Fine

## SQL Files

- `ddl.sql` – Database structure and table definitions
- `dml.sql` – Data insertion and modification
- `queries.sql` – SQL queries, aggregate functions, and joins
